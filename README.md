## 本地预览

```sh
python3 -m http.server 3002 --bind 127.0.0.1 --directory dist
```

访问 `http://127.0.0.1:3002/`。部署目录是 `dist/`。

## GitHub Pages 发布

`main` 保存源文件；`gh-pages` 分支只包含 `dist/` 内容，独立于原有科研主页。

```sh
git add README.md dist
git commit -m "Update exhibition"
git push origin main
git subtree push --prefix=dist origin gh-pages
```

在 GitHub Pages 中使用 `gh-pages` 分支的根目录。无需 Node.js 安装、构建步骤或访问者登录。

## 图像说明

手绘作品由用户提供。全部二十幅图纸或图组按用户要求由内置 ImageGen 辅助重绘，以改善清晰度和拍摄偏色。各图以原展板的真实独立图纸为参考，不再裁切同一张主透视来冒充独立图纸；锈色作品左、右两张水庭透视单独处理，不拼为全景。此次对照原板补齐十二幅植物、节点、剖面与分析图。网站按用户要求仅展示清晰版本，不含原始拍摄对比。重绘保留主要构图，但局部柱位、曲线、植物、图例和细小标注存在变化，不等同于无损修复、测绘图或准确还原原纸色彩。无法确认的手写文字未猜写。原始资料留在本地，不包含在此仓库中。

`prepare-panels.cjs` 与 `prepare-supplement.cjs` 仅将完整 PNG 图纸转换为 WebP，不做裁切或拼接。退役的主图裁片已移出发布目录并保留在本地备份中。

图像已移除 EXIF / GPS 元数据。所有尺寸在 HTML 中声明，非首屏图像延迟加载。

设计师肖像由内置 ImageGen 基于本人提供的照片生成，按用户要求更新为正面、正式着装、精致妆容与透明背景。原始私人肖像照片不包含在此仓库中。

展板悬浮与画廊打开使用 CSS transform / opacity；背景使用低分辨率 WebGL 色彩流动（30fps 上限，最长画布 680×1000），不变形图纸、不劫持滚动、不随滚动隐藏内容。屏幕外、后台标签页、画廊打开时停止背景动画；系统减少动态效果默认暂停，并提供手动开关。WebGL 不可用时显示静态渐变。键盘焦点在关闭画廊时返回打开入口。
